# AICR web design direction

Developer workspace: dark graphite surfaces, restrained chartreuse accent, IBM Plex
Sans UI and JetBrains Mono source. Both fonts are bundled locally. Dense source and
finding views use explicit labels, outlines and icons, not color alone. No chat avatars,
invented analytics or implied model activity.

The UI/UX skill returned relevant developer typography and dark-dashboard guidance.
Its FAQ landing pattern remained off-topic after one narrower retry, so that pattern
is not adopted. The product flow follows the requested review workflow instead.

Global sidebar: Overview, New review, Repositories, History, Settings. The workspace
centers on source selection, code and findings, with a real execution timeline below.
On small screens it stacks these surfaces. Keyboard focus, reduced motion, readable
contrast and explicit empty/error/pending states are required throughout.

Motion in Phase 2 is limited to subtle transitions and a truthful running indicator.
Phase 3 can enhance the event-driven pipeline visualization without changing its data.
